# VerifyAI — AI Trust & Information Verification Platform

> **Don't just trust AI. Verify it.**

VerifyAI is an AI-powered verification platform designed to help users determine whether information generated by AI or found online can be trusted.

Instead of asking whether text was written by AI, VerifyAI asks a more useful question:

**"Are the factual claims inside this content supported by reliable evidence?"**

---

## 🚨 Problem

Generative AI can produce confident-sounding answers that contain incorrect facts, outdated information, misleading statistics, or hallucinated claims.

Users often have no quick way to check every factual statement manually.

VerifyAI addresses this problem by automatically breaking content into claims, finding external evidence, and evaluating each claim.

---

## 💡 Solution

VerifyAI creates an evidence-backed verification pipeline:

```text
AI / User Content
       ↓
Claim Extraction
       ↓
Web Evidence Search
       ↓
AI Evidence-Based Reasoning
       ↓
Claim Classification
       ↓
Reliability Score
       ↓
Explainable Verification Report
```

Each claim is classified as:

- ✅ **Supported**
- ⚠️ **Partially Supported**
- ❌ **Contradicted**
- ❓ **Cannot Verify**

The platform also displays the evidence used for the decision.

---

## 🤖 AI Implementation

VerifyAI uses AI as a reasoning component rather than as a simple chatbot.

### Featherless AI

Featherless AI provides the language-model inference used for:

- extracting factual claims
- comparing claims with retrieved evidence
- reasoning about whether evidence supports a claim
- classifying verification status
- generating explanations

### Tavily

Tavily provides web evidence retrieval.

The system searches for relevant external information and passes the retrieved evidence to the AI verification pipeline.

This creates an evidence-grounded workflow instead of relying only on model knowledge.

## ⚙️ Setup

### 1. Clone the repository

```bash
git clone https://github.com/abhiram0212/VerifyAI.git
cd VerifyAI
```

### 2. Install backend dependencies

```bash
cd backend
pip install -r requirements.txt
```

### 3. Create `.env`

Create `.env` in the project root:

```env
FEATHERLESS_API_KEY=your_featherless_api_key
TAVILY_API_KEY=your_tavily_api_key
GOOGLE_CLIENT_ID=your_google_client_id
```

Never commit this file to GitHub.

### 4. Start the backend

From the `backend` directory:

```bash
python -m uvicorn main:app --reload
```

### 5. Start the frontend

Open:

```text
frontend/index.html
```

using VS Code Live Server.

The frontend communicates with the local FastAPI backend.

## ▶️ Usage

1. Sign in with Google.
2. Select a verification mode.
3. Enter content, code, PDF, or URL depending on the mode.
4. Start verification.
5. VerifyAI extracts claims.
6. Tavily searches for external evidence.
7. Featherless AI evaluates the claim against the evidence.
8. The dashboard displays the result and reliability score.
9. Review the evidence sources for each claim.

## 🧠 Why VerifyAI Is Different

Traditional AI detectors ask:

> **"Was this text generated by AI?"**

VerifyAI asks:

> **"Can the information in this content be trusted?"**

This makes VerifyAI an **AI trust layer** rather than another AI chatbot.

The system combines:

**AI reasoning + external evidence + claim-level decisions + explainability**
